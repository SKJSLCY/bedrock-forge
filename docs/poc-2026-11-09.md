# BDS on Android — PoC 记录（2026-11-09）

## 设备
- Redmi M2007J3SC（Redmi K30S Ultra / apollo）
- Android 17（API 37），arm64-v8a
- Snapdragon 865（SM8250），8GB RAM
- 226GB 存储，当前剩余约 182GB
- 未 root，SELinux Enforcing

## 运行环境（全部在手机 /data/local/tmp/mcbds）
- proot 5.1.107.102（Termux 包，bionic）
- Ubuntu Base 24.04.3 arm64（glibc 2.39）
- box64 0.3.4（Debian trixie arm64 包）
- 官方 BDS 1.26.63.1 Linux x64
- x86_64 libgcc_s.so.1（Debian trixie amd64 包，box64 需要）

## 启动方式
```sh
cd /data/local/tmp/mcbds
# 控制台输入队列：往 cmd.log 追加一行就是一条命令
tail -f cmd.log | ./run.sh
```

run.sh 关键内容：
```sh
BASE=/data/local/tmp/mcbds
export PROOT_TMP_DIR=$BASE/tmp
export PROOT_LOADER=$BASE/proot/libexec/loader
export PROOT_LOADER_32=$BASE/proot/libexec/loader32
export LD_LIBRARY_PATH=$BASE/proot/lib
exec $BASE/proot/proot -0 -r $BASE/rootfs \
  -b /dev -b /proc -b /sys -b $BASE/server:/server -w /server \
  /usr/bin/env -i HOME=/root PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin \
  TERM=xterm \
  LD_LIBRARY_PATH=/server:/usr/lib/aarch64-linux-gnu:/lib/aarch64-linux-gnu:/usr/lib \
  BOX64_LD_LIBRARY_PATH=/server \
  BOX64_LOG=0 BOX64_MMAP32=1 BOX64_NOSIGSEGV=1 BOX64_PAGESIZE=4096 \
  BOX64_DYNAREC_WAIT=1 BOX64_DYNAREC_STRONGMEM=1 \
  /usr/bin/box64 ./bedrock_server
```

## 已验证
- BDS 1.26.63.1 启动成功，输出 `Server started.`
- 空闲 TPS：`time query gametime` 两次采样 192 ticks / 9.512s ≈ 20.19 TPS
- 内存：约 1.33GB RSS，28 线程
- 控制台命令可用：`list`、`time query gametime`、`say`
- NetherNet signaling 可用：`GET http://192.168.5.20:19132/v1/join`
  - 返回 `{"name":"Dedicated Server","protocol":2225,"version":"1.26.63",...}`
- PC 可建立到 192.168.5.20:19132 的 TCP 连接
- 服务器离线模式可运行（`online-mode=false`，`allow-list=false`）

## 已发现的限制
1. **online-mode 失败**：`Could not connect to Minecraft services. This is required to accept connections in online mode.` 服务器随后退出。原因待定位（网络限制或 Box64 TLS）。
2. **离线模式不能开白名单**：`Using an allowlist without online authentication can be dangerous and is not allowed.` BDS 直接拒绝启动。
3. **BDS 1.26 只支持 NetherNet**：`transport=raknet` 会报 `NetherNet is the only supported transport type. Players will not be able to connect.`
4. **NetherNet 端口**：TCP 19132 做 HTTP signaling；游戏流量走 UDP（默认 `server-udp-ports=19132`，多人建议改端口范围）。
5. **客户端版本**：电脑上只有 Minecraft 1.21.114 / 1.21.120，服务器是 1.26.63，协议不匹配；需要 1.26.60+ 客户端才能测试进服。
6. **iOS 已知问题**：NetherNet 明文 HTTP 下 iOS 可能报 TLS alert 40 / InitialConnection-13（BDS 自身 bug，x86_64 也有）；Android/Windows 客户端会回退到 HTTP。局域网 Android/Windows 预计可进，但未实测。
