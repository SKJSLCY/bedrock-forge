# MC BDS · UI 重设计 v2（三套方案）

依据手绘草图：服务器信息 → 运行状态/玩家 → 服务器负荷（CPU/内存/网络/TPS）→「服务器管理」→ 底部「首页 / 控制台 / AI / 设置」。

三套方案都保留了草图的全部信息，但交互模型不同：

| 方案 | 关键词 | 适合 |
|---|---|---|
| A 监控台 | 深色、数据密度、霓虹绿、实时感 | 每天看状态、调参数、排障 |
| B 极简卡片 | 浅色、留白、大字号、低认知负担 | 只想“开服/进服”，不想看太多 |
| C 方块世界 | Minecraft GUI、像素、任务化 | 想要“这就是 MC 的一部分” |

---

## 方案 A · 监控台（Server Control Deck）

**视觉**：近黑背景 + 网格、荧光绿 `#3DFFA2`、青色 `#45C8FF`、等宽数字；状态用红/绿呼吸点。

**首页结构**
1. 顶部：`MC BDS` + `SERVER CONTROL DECK`，右侧状态胶囊「已停止」。
2. 三格元信息：服务器类型 / 服务端版本 / 协议·游戏版本。
3. 英雄区：玩家 `0/10` + CPU 环形仪表 `50%`。
4. 负荷 2×2：CPU、内存、网络吞吐、TPS（分段条）。
5. 世界实例：`Nether62 :19134`、离线模式、身份密钥已保存。
6. 最近事件：LIVE 日志（stop requested / Quit correctly）。
7. 快捷操作：启动服务 / 打开控制台 / 备份世界。
8. 如何进入：同一 Wi-Fi → 游戏→世界 → 点击 Phone12662B。
9. 主 CTA：「服务器管理」渐变绿大按钮。
10. 底部导航：首页 / 控制台 / AI / 设置（图标 + 文字，绿色激活态）。

**交互**
- 点「服务器管理」→ 70% 高度 **Bottom Sheet**，三个分段：控制 / 世界 / 设置；上滑展开。
- 点任意指标卡 → 该指标的 60 秒趋势 Bottom Sheet（CPU、TPS、网络）。
- 控制台是独立全屏页：终端日志 + 固定命令条 + 快捷命令 chips（`list`、`say`、`time query gametime`、`stop`）。
- 启动/停止用**长按确认**或二次确认，避免误触；停止时按钮变「停止中…」并显示进度。
- 端口未监听 → 首页顶部出现琥珀色 Banner：「端口未就绪，正在自动重试（60s）」+ 手动重试。
- Shizuku 未运行 → 顶部红色 Banner + 「如何启动 Shizuku」。
- AI 页：对话式，预置上下文（当前状态、最近日志、server.properties），快捷问题「为什么 TPS 低」「帮我改 server.properties」。

**优点**：信息密度高、排障友好、像专业控制台。
**代价**：视觉较重；对“只想开服”的用户信息偏多。

## 方案 B · 极简卡片（Clean Minimal）

**视觉**：浅灰背景 `#F2F5F8`、纯白卡片、28px 圆角、柔和阴影、黑色主按钮、绿色点缀。

**首页结构**
1. 顶部：小标题「服务器概览」+ 大标题 `Minecraft BDS`，右侧灰色状态胶囊。
2. 英雄卡：超大玩家数 `0/10`；右侧「离线模式」绿标签 + 服务端/协议/游戏版本。
3. 2×2 指标卡：CPU / 内存 / 网络 / TPS（细进度条 + 小图标）。
4. 世界与实例：世界名、端口、身份密钥。
5. 最近事件：两行日志。
6. 快捷操作：启动服务 / 控制台 / 备份（浅色按钮）。
7. 如何进入：三步卡片。
8. 主 CTA：深色「服务器管理」+ 圆形箭头。
9. 底部导航：白色悬浮胶囊，激活项为黑色胶囊。

**交互**
- 首页是**只读概览**；「服务器管理」进入**全屏管理页**：顶部大状态 + 一个超大主按钮（启动/停止），下方分段「设置 / 世界 / 备份」。
- 点指标卡 → 轻量详情页（趋势 + 说明），不做 Bottom Sheet。
- 控制台：全屏深色终端，进入即聚焦输入框。
- AI：聊天页，输入框固定底部。
- 设置：分组列表（服务器、连接、Shizuku、关于）。
- 状态变化用**整页状态**表达（未安装/已停止/启动中/运行中/错误），而不是小徽章。

**优点**：最易实现、认知负担最低、适合日常快速开服。
**代价**：信息密度低，排障时需要多点一层。

## 方案 C · 方块世界（Minecraft GUI）

**视觉**：泥土/石头像素背景、Minecraft 灰色 GUI 面板、3D 内凹/外凸边框、像素方块图标、绿色 Creeper 强调色 `#5BC236`、底部物品栏式导航。

**首页结构**
1. 像素 Logo `MC BDS` + `MINECRAFT BDS SERVER`，右上红石灯「已停止」。
2. 「服务器信息」GUI 面板：类型 / 服务端版本 / 游戏版本 / 世界·端口；下方两个状态槽：运行状态（红「关闭」）、玩家在线（绿 `0/10`）。
3. 「服务器负荷」面板：2×2 物品槽，CPU / 内存 / 网络 / TPS；像素分段进度条。
4. 「今日任务」面板：启动服务端 / 局域网连接一次 / 邀请玩家（完成打勾）。
5. 「如何进入」面板：三步。
6. 主 CTA：Minecraft 风格灰色凸起按钮「服务器管理」，按下有下沉感。
7. 底部导航：物品栏（hotbar）四个槽位，激活槽绿色高亮。

**交互**
- 点「服务器管理」→ **箱子/背包弹窗**（Chest UI）：2×3 物品格，分别代表 启动 / 停止 / 控制台 / 备份 / 设置 / 关闭；点物品有 tooltip 与像素按压反馈。
- 任务面板随操作自动勾选，给“开服”一点游戏化反馈。
- 控制台是「命令方块」风格终端，绿色等宽字，命令历史用上下箭头。
- AI 是「向导 NPC」对话框，头像 + 聊天气泡。
- 危险操作（停止、删除世界）用 TNT/红石警告样式二次确认。
- 可选：像素音效、按钮按下位移 4px、启动时经验条式进度。

**优点**：最强的 Minecraft 身份感，任务化让开服有反馈。
**代价**：实现成本最高（9-patch/像素素材、字体、弹窗），信息密度与可读性需要控制。

## 共享状态与数据

```text
status: uninstalled | stopped | starting | running | stopping | error
serverType, serverVersion, protocol, gameVersion
players, maxPlayers
cpuPercent, memoryUsedGb, memoryTotalGb
netUpMbps, netDownMbps
tps, worldName, port, uptime, identitySaved
recentEvents[]
shizukuReady, portListening
```

**全局提示（三套都需要）**
- 未安装环境：引导安装（Shizuku 方式）。
- Shizuku 未运行：Banner + 启动指引。
- 启动中：显示阶段（QEMU → 世界加载 → 监听端口）。
- 运行中但端口未监听：琥珀 Banner + 自动重试，不显示“假运行中”。
- 离线模式：提示“手动地址可能 124，请用局域网世界”。

## 推荐

- **日常自用、想看数据**：选 A。它的结构最接近你画的草图，也最适合排障。
- **想最快做完、最稳**：选 B。实现成本最低，后续加功能也容易。
- **想要 Minecraft 氛围**：选 C。最适合作为“个人服主工具”的差异化外观。
- **混合建议**：A 的布局 + C 的像素图标/任务面板，既保留数据密度又有 MC 味道。

## 实施成本

| 方案 | 主要工作 | 成本 |
|---|---|---|
| A | 底栏 + 首页卡片 + Bottom Sheet + 趋势图 + 控制台页 | 中 |
| B | 底栏 + 首页卡片 + 全屏管理页 + 控制台页 | 低 |
| C | 像素 9-patch/图标 + 箱子弹窗 + 任务系统 + 底栏 | 中高 |

当前 App 是单页 Java 程序化 UI；三套都需要先拆成 **首页 / 控制台 / AI / 设置** 四个页面 + 底部导航，再套对应视觉。
