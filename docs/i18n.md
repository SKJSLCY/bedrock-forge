# 界面语言（i18n）实现说明

本应用支持 **简体中文（zh_CN，默认）**、**繁體中文（zh_TW）**、**English（en）**，
切换入口在「设置 → 语言」，切换后界面立即重建生效，不需要重启应用。

## 设计

界面文字全部用 Java 代码构建，没有 XML 布局，所以翻译不依赖 Android 资源系统：

```text
app/src/com/skjslcy/bedrockforge/I18n.java     语言状态、词条查表、资源改名
app/assets/i18n/ui/lang_zh_TW.json             繁體中文词条
app/assets/i18n/ui/lang_en.json                English 词条
app/assets/i18n/<lang>/fields.json             玩家数据字段名
app/assets/i18n/<lang>/item_names.tsv          物品名称
app/assets/i18n/<lang>/effects.json            药水效果
app/assets/i18n/<lang>/enchants.json           附魔
app/assets/i18n/<lang>/attributes.json         属性
app/assets/legal/user_agreement_<lang>.txt     用户协议
app/assets/legal/changelog_<lang>.txt          更新日志
```

**词条的键就是简体中文原文**，例如：

```java
I18n.t("服务端部署完成")
```

简体中文直接返回原文，其余语言查表；查不到时回退原文，因此新增文案不会导致空白或崩溃。

## 用法

| 场景 | 写法 |
|---|---|
| 普通文案 | `I18n.t("取消")` |
| 带参数 | `I18n.f("切换为 %s？", name)` |
| 新建文本 | `MinecraftUi.text(ctx, "标题", 9f, color, false)` |
| 按钮 | `new MinecraftUi.McButton(ctx, "确定")` |
| 面板标题 | `MinecraftUi.panel(ctx, "设置")` |
| 键值行 | `MinecraftUi.infoRow(ctx, "版本", valueView)` |
| 已有 TextView | `tv.setText(I18n.t(text))` |
| 拼接片段 | `I18n.t("已下载 ") + n + I18n.t(" MB")` |

`MinecraftUi.text`、`McButton`、`panel`、`infoRow`、`valueText`、`terminalInput`
内部已调用 `I18n.t`，直接把中文传进去即可。

## 不要翻译的字符串

以下内容必须保持简体中文原文，否则逻辑会失效：

- 比较用的键：`"主题".equals(title)`、`"players".equals(kind)`
- 持久化值：写进 SharedPreferences、instance.json、`.mcbds_version` 的字符串
- 服务端解析：`server.properties`、控制台日志、`level-name=` 之类
- 文件名、包名、URL、shell 命令、正则表达式

需要在界面上显示这些值时，在**显示处**套 `I18n.t(...)`，而不是修改原值。

## 新增一门语言

1. 在 `I18n.java` 的 `LANGUAGES` 中登记 `{代码, 语言自称}`，并在 `normalize()` 中识别代码。
2. 复制 `assets/i18n/ui/lang_en.json` 为 `lang_<code>.json` 并翻译全部词条。
3. 复制 `assets/i18n/en/` 目录为 `assets/i18n/<code>/`，翻译 `fields`、`item_names` 等字典。
4. 复制 `assets/legal/user_agreement_en.txt`、`changelog_en.txt` 为对应语言版本。
5. `I18n.suffix()` 增加 `_<code>` 映射，供协议、日志等文件按语言改名。

## AI 提示词与回复语言

内置的系统提示词是「一段多行中文」，存于 `AiConfig.PROMPTS`，按行分别登记词条，
运行时用 `I18n.tl(block)` 逐行翻译（词条可能带 `\n` 或 `\n\n`，`tl()` 会依次尝试整段、
行+`\n\n`、行+`\n`、行 四种匹配，避免空行处的词条落空）。

`AiConfig.systemPrompt()` 会在提示词末尾追加一条语言指令：

```text
（zh_CN）请一律使用简体中文回答；技术名词保留英文原名（allow-list、TPS、LevelDB）。
（zh_TW）一律使用繁體中文（台灣用語）回答；技術名詞保留英文原文（allow-list、TPS、LevelDB）。
（en）  Always reply in English. Keep technical terms in English (allow-list, TPS, LevelDB).
```

否则模型会沿用提示词里的「使用中文」而用简体回复，繁体/英文界面看起来就像没翻译。

## 校验

`.tooling/i18n/` 下是开发期使用的脚本（不纳入版本库）：

```text
extract.py   扫描源码中的中文字面量并统计上下文
apply.py     给界面字面量补 I18n.t(...)
fixups.py    针对比较/持久化路径的人工修正
verify.py    校验每个运行时会查表的字面量都有译文
merge.py     合并译文分片，写入 assets
```

`verify.py` 会比对源码中所有 `I18n.t(...)`、`I18n.f(...)` 字面量以及
`MinecraftUi.*` 的文案参数，缺少译文会直接报错并给出行号。
