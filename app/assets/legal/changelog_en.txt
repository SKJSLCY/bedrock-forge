Bedrock Forge Changelog

0.3.0 (2026-11-24)

What's new:

· Editing player data now really works: in big worlds, changes to level, inventory or coordinates used to show "written" while the game kept the old values — fixed, and the change takes effect once you start the server
· Saving takes seconds instead of a couple of minutes
· Opening player data in a big world takes seconds instead of minutes (the very first open still reads the whole world, about a minute)
· The app cache went from about 8 GB down to about 2 GB

New

· Guardian system: Players → Guardian system sets a whitelist or a blacklist; the two lists are kept separately
· Guardian system: write your own message — blocked players see it
· Guardian system: players are stopped as soon as they join, no need to wait until they walk into the world
· Guardian system: the block log can be searched, filtered, imported and exported

Improved

· Every import (server, addons, world, backup) shows live progress — how much has been copied and which file is being unpacked
· Reading player data has a progress bar and can be cancelled halfway
· The save result is now a window you dismiss with "OK" instead of a toast that disappears by itself
· After saving, the player data screen refreshes with the new values — no need to leave and come back
· "Roll back player data" and "import player data into another world" did nothing before; now they work, and rolling back into the same world restores everything instead of only part of it
· "Delete player data" now backs up the whole world first
· The online player count on the home page no longer flickers to "connecting…" every few seconds; when a player leaves the number simply drops by one
· New console lines no longer jump the view back to the top

Fixed

· Added the 38 missing translations — the English and Traditional Chinese screens no longer show Simplified Chinese text

Notes

· Stop the server before importing or editing saves (same as before)
· Install over the old version; worlds and settings are kept
· The first time you open player data in a big world it has to read the world once (about a minute); after that it opens instantly
0.2.1 (2026-11-22)

New

· Deploy runtime now offers -j6 / -j8
· Repair runtime now offers -j1 / -j2 / -j4 / -j6 / -j8

Improved

· Server load metrics now refresh more often
· Closing the app now stops the server by default, preventing save corruption from an abnormal shutdown

0.2 (2026-11-14)

What's new:

· Interface language: Settings → Language switches between Simplified Chinese, Traditional Chinese and English — the change applies immediately, no restart needed
· The whole app follows the language you pick: home, server, console, players, worlds, backups, AI assistant, settings and about
· Item names, enchantments, potion effects and attribute names in player data follow the language too
· The user agreement and this changelog are available in all three languages
· New Settings → Keep screen on, where you choose when the screen stays awake. The page warns that long screen-on time can cause burn-in and screen aging — use it as needed
· The Ore theme was rebuilt to match the Bedrock interface: colours, buttons, switches and panels are closer to the game
· Buttons now show three states: not selected, selected, and selected + pressed (in the Ore theme a pressed button sinks slightly)
· In the server instance and world lists, the one in use is highlighted directly instead of adding "(Current)" after the name
· "Liquid glass" was renamed to "Glass"
· Fixed several display issues: Simplified characters inside the AI system prompt, unreadable chat bubbles in the Minimal theme, untranslated input hints, "1 players" style plurals in English, and wrong brackets on the About page
· The About page no longer shows the "tested with BDS…" line, and Testing & feedback now credits SKJSLCY
· Version bumped to 0.2.0

· Fixed: -j6 / -j8 were internally clamped to -j4; the chosen thread count is now used

0.1 (2026-11-13)

Initial release:
· Brand renamed: 基岩工坊 / Bedrock Forge
· Package name migrated to com.skjslcy.bedrockforge
· Added a dedicated splash screen (SplashActivity)
· Added user agreement and first-launch consent flow
· Added an About page: version, environment info, diagnostics, FAQ, acknowledgements
· AI assistant: multiple sessions, non-streaming conversations, images/files, model and reasoning effort
· AI agents: multiple providers, encrypted API keys, model detection, system prompt presets
· Server: deploy, start, stop, restart, console, logs
· Players: list, permissions, game mode, level, data view/edit/delete/backup
· Worlds: create, switch, rename, delete, import, export, backup and rollback
· Addons: import, detect, enable, disable, delete
· Settings: theme placeholder, permission management, keep screen on, clear all data
